MINI COMPILER TEST CASES
=========================

Test 1: Assignment and Declaration
Input:
int a,b;
a = 5;
b = 10;

Expected Result:
Successful compilation with TAC for both assignments.

Actual Result:
Compilation successful.

Generated TAC:
0: a = 5
1: b = 10

Status: PASS


Test 2: If-Else
Input:
int a, b, x;
a = 5;
b = 10;
if (a < b) {
    x = a + b;
} else {
    x = a - b;
}

Expected Result:
Successful compilation with conditional jumps and TAC.

Actual Result:
Compilation successful.

Generated TAC:
0: a = 5
1: b = 10
2: if< a, b goto 4
3: goto 7
4: t0 = a + b
5: x = t0
6: goto 9
7: t1 = a - b
8: x = t1

Status: PASS


Test 3: While Loop

}

Compilation successful.

Generated TAC:

Test 4: Nested If-Else Inside While
Input:
int a, b, x;
a = 0;
b = 5;

while (a < b) {
    if (a < 3) {
        x = a + b;
    } else {
        x = a - b;
    }
    a = a + 1;
}

Expected Result:
Successful compilation with nested control-flow TAC and backpatching.

Actual Result:
Compilation successful.

Generated TAC:

1: b = 5
2: if< a, b goto 4
3: goto 14
4: if< a, 3 goto 6
5: goto 9
6: t0 = a + b
7: x = t0
8: goto 11
9: t1 = a - b
10: x = t1
11: t2 = a + 1
12: a = t2
13: goto 2

Status: PASS
